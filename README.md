# FinTrack — Personal Finance App

A full-featured personal finance tracking app built with **Next.js 16**, **TypeScript**, and **Tailwind CSS v4**.

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Features
- Secure login page
- Dashboard with balance, income, expenses, savings + trend charts
- Monthly pages (May–December 2026) with full transaction CRUD
- Running balance per transaction (like a bank statement)
- Annual summary with category breakdowns
- Investments page with P&L and ROI tracking
- All data persisted to localStorage

## Tech Stack
- Next.js 16 App Router
- TypeScript
- Tailwind CSS v4
- Recharts (charts)
- Lucide React (icons)
- Google Fonts: Cormorant Garamond + DM Sans
